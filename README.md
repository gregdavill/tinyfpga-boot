# TinyFPGA BX Bootloader

A USB bootloader for the [TinyFPGA BX](https://tinyfpga.com/) (Lattice iCE40LP8K) written in [Amaranth HDL](https://amaranth-lang.org/). Uses the [LUNA](https://github.com/greatscottgadgets/luna) USB library for a direct I/O full-speed USB device interface.

## Features

- Implements UF2 bootloader standard
